# Sabeel114 LMS

Sabeel114 LMS is a learning management system built to support the day-to-day educational workflows of Sabeel114.

The platform provides a centralized system for managing students, teachers, parents, classes, user accounts, and student activity while giving different users access to the tools relevant to their role.

## Core Features

- Student, teacher, and parent account management
- Class creation and management
- Assigning students and teachers to classes
- Parent and student account relationships
- Student activity and progress logging
- Role-based user access
- Student and class views
- Leaderboards and progress tracking
- Authentication and account management

## Technology Stack

### Frontend
- React Native
- Expo
- React Navigation
- Axios

### Backend
- Python
- Django
- Django REST Framework
- JWT authentication

### Database
- SQLite for local development
- PostgreSQL support
